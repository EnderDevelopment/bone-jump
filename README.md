# Bone Jumping Game

This project is a Roblox game featuring bone-jumping mechanics, an admin panel, and player interfaces. The game allows players to jump on bones, which are scattered throughout the game world. The admin panel provides tools for managing players and the game environment, while the player interfaces offer a user-friendly way for players to interact with the game.

## Install

1. Download the project files from the GitHub repository.
2. Open your Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the `BoneJumpingMechanics.lua` script in the `Workspace` folder.
5. Place the `AdminPanel.lua` script in the `ServerScriptService` folder.
6. Place the `PlayerInterface.lua` script in the `StarterGui` folder.

## Use

1. Start the game in Roblox Studio or publish it to Roblox.
2. Players can jump on bones to progress through the game.
3. Admins can use the admin panel to manage players and the game environment.
